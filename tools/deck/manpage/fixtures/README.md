# Manpage fixtures

Real manpages, checked in so the parser's snapshot tests run without the tools installed. Each keeps its own license; they are test data only and are not shipped in the app.

| File        | Source                                        | Format | License          |
| ----------- | --------------------------------------------- | ------ | ---------------- |
| `rg.1`      | ripgrep 14.1.0 (Ubuntu 24.04 `ripgrep`)       | man(7) | MIT OR Unlicense |
| `git-log.1` | git 2.43.0 (Ubuntu 24.04 `git-man`)           | man(7) | GPL-2.0-only     |
| `sed.gnu.1` | GNU sed 4.9, generated by help2man            | man(7) | GPL-3.0-or-later |
| `sed.bsd.1` | FreeBSD `usr.bin/sed/sed.1` (main, June 2025) | mdoc   | BSD-3-Clause     |

When a tool exposes a parser bug, add its page here, add a case to `../manpage.test.ts`, and commit the new snapshot under `__snapshots__/`.
